## Selection and routing

| Need | Use now | Optional source capability |
| --- | --- | --- |
| Domain and architecture | agentos-builder, arms-architecture | No external tool required |
| Spatial interface | spatial-design, widget-contract, design procedures | imagegen for actual bitmap needs; no image tool required for layout |
| Memory | memory-routing | Obsidian / JSON Canvas / data context if the user actually uses them |
| Scheduled work | routine-engineering | A verified scheduler and authorized infrastructure |
| Applications | application-integration, capability-policy | Exact authorized platform CLI/API/MCP |
| Security | capability-policy, agentos-verify | Scope-appropriate security workflow, not all scans indiscriminately |
| Analytical artifact | evidence-review | Analytics, spreadsheets or document workflows when the artifact needs them |
| Assistant | agent-runtime, composer-and-voice | Provider-specific docs checked during integration |

Do not load this entire catalog as system instructions. A task router should select a few relevant, installed project skills. To add third-party material, record source URL, immutable version, license, local path, allowed tools, inputs/output, and verification evidence. Do not copy proprietary runtime glue into a public template.
