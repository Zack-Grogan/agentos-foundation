# Project skill library

These 37 original skills are scoped to this repository under `.agents/skills/`. They are usable as ordinary agent-readable playbooks even if a client does not automatically discover that path. Read the needed SKILL.md directly; do not assume every client supports the same native invocation. No global install is required.

Use `agentos-builder` to begin and `spatial-design` before interface work. Keep entry points short and load references selectively. The repository check verifies front matter and reference links.
