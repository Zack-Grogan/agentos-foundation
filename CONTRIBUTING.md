# Contributing

Keep this foundation domain-neutral and project-scoped. Prefer a complete workflow over another integration stub. Explain the user-visible behavior and include evidence for affected boundaries. Run the tests and repository checks. Render UI changes at desktop and narrow widths.

New skills need a short entry point, referenced supporting material, explicit inputs/output, failure behavior and an example. Do not vendor third-party skill bundles or reference PDFs without establishing their license and retaining required notices. Never commit personal workspace data or transcripts. Update provenance when adding an external source.
