# Workspace critique and acceptance

Score each category 0 (missing), 1 (partial), or 2 (verified). Record evidence and the smallest useful correction. A visually attractive average cannot compensate for a failure in authority, truth or accessibility.

| Category | Question | Evidence |
| --- | --- | --- |
| Domain fit | Does the composition express this domain’s objects and relationships? | Complete the primary job without interpreting generic OS categories |
| ARMS integration | Can a result be traced through source, skill, run and review? | Open each from one real artifact |
| Spatial hierarchy | Is one work surface dominant, with stable supporting tools? | Compare entry, inspector and drawer screenshots |
| Attention | Are real review/failure states visible without manufactured urgency? | Seed one failure and one draft |
| Density | Are useful contents high on the screen and readable? | Inspect 1440px and 1024px widths |
| Continuity | Does returning preserve selection and location? | Open a detail and source, return twice |
| Accessibility | Can a keyboard and a click-only pointer complete the same task? | Focus path, Escape, visible focus, arrangement controls |
| Responsive behavior | Is the narrow layout a useful composition? | 390px width, zoomed text, long titles |
| Truth | Are unknown/stale/partial states explicit? | Failure fixtures with no invented metrics |
| Agency | Are run, review and permission states distinct? | Try stale review and duplicate launch |
| Craft | Do typography, spacing, color and motion support the task? | Compare three compositions, then render selected result |
| Recoverability | Can hidden tools, missing sources and failed jobs be recovered? | Hide/restore widget, refresh failure, restart |

Release requires every authority/truth/accessibility issue to be resolved or the relevant feature disabled. Save desktop and narrow screenshots without personal data. A screenshot proves layout, not backend completion; link workflow receipts separately.

Anti-patterns: sidebar full of one-widget pages; marketing hero; equal-size cards everywhere; concentric decoration with no record relationships; animated fake activity; unreadable map labels; chat as the only way to act; hiding failures to improve the screenshot; a layout reset that deletes data.
