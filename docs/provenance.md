# Sources, review scope and redistribution

## ARMS sources

- **RoboNuggets, ARMS — The Agentic OS Guide**, supplied as `ARMS-Agentic-OS-Guide.pdf`, 17 pages. Framework and levels: p. 2; skills: pp. 3–5; memory: pp. 6–7; routines: pp. 8–9; applications: pp. 10–12; command centre: pp. 13–14; adoption sequence: p. 15. The guide identifies [RoboNuggets](https://www.skool.com/robonuggets) as its source.
- **ARMS / ChatGPT + Codex, Field Guide**, supplied as `ARMS-ChatGPT-Codex-Guide.pdf`, dated 2026-09-04, 17 pages. Same framework; adds explicit execution surfaces, source-aware memory, bounded runner requirements, review separation and acceptance evidence. Product compatibility notes are dated; they are not treated as current platform guarantees.

This repository provides an independently written synthesis and implementation. The PDFs and their copy-paste prompt collections are **not redistributed**, because no public redistribution license was established for the original guide. The MIT license applies to this repository’s original work, not the upstream framework’s documents or brand. No affiliation or endorsement is claimed.

## Public export policy

Include only original docs, source, templates, synthetic fixtures, and screenshots of the fresh reference. Exclude private chats, personal paths, credentials, raw provider payloads, runtime databases, original downloads, prior app screenshots and personal account data. Adding user-provided material later requires its owner to establish redistribution rights and remove private data first.
