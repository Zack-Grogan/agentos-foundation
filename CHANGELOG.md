# Changelog

## 0.2.0 — 2026-09-08

Complete local ARMS workflow: explicit file import, durable provider jobs, source-aware memory, paused interval routines, review and task progress. Added static provider diagnostics, configured HTTP/ACP job paths, wall-time/cancellation/output limits, source/config fencing and interrupted-worker handling.

Added schema migrations with recovery copies, missing/future/foreign database refusal, checksummed consistent backup and verified restore to new directories. Restores pause routines and interrupt pending work.

Widget settings now persist server-side with revision conflicts, collapse/density/placement controls and functional profiles sharing a layered orbital center with contextual workbench/board views. Fixed Escape behavior and late-save window reopening. Existing v0.1 browser-only layout preferences are not imported because they were not workspace-scoped; their values are not deleted.

Scaffolding now copies a reviewed manifest rather than arbitrary directory contents. New copies record a baseline for read-only three-way update planning. Added worked examples, quickstart/provider setup, explicit readiness scope and fresh-copy/browser acceptance.

## 0.1.0 — 2026-09-08

Initial ARMS playbook, 37 project skills, spatial app/composer rules, provider compatibility research, offline reference and transport modules.
