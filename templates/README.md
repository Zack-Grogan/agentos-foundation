# Working templates

Copy only what the current phase needs. Replace every bracketed field with an observed fact, an explicit choice, or `unknown`. Never fill a template with invented user facts.

- `product-brief.md`: first useful workflow and success.
- `capability-matrix.md`: actual tools, access and evidence.
- `domain-model.md`: identities, relationships and ownership.
- `design-brief.md`: composition, states, visual rules.
- `work-order.md`: bounded execution request.
- `skill.md`: portable procedure entry point.
- `routine.json`: disabled scheduling contract.
- `widget.json`: presentation contract.
- `context-index.md`, `decision.md`, `handoff.md`: durable navigation and continuity.
- `integration.md`: exact application operation and verification.
- `review.md`: artifact-specific decision.
